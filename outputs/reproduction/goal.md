# SpaceServe / EPD 双 H20 小规模复现目标

在 qjh003 和 qjh005 两台 H20 机器上完成 EPD Disaggregation 小规模复现，与已有 SpaceServe 的 4090/L20 实验一起，形成可信、可重复的实验报告。

1. 固定官方代码、模型和主要依赖，解决 H20 cuBLAS 兼容问题。两台分别验证 CUDA P2P、原生 embedding/KV 传输、冷启动及重启后的并发正确性，保存版本、补丁和校验记录。
2. qjh003 完成 EPD 全矩阵；qjh005 独立复测低、高负载点。每台在单机内运行 E:P:D=1:1:1，并与同机、同三张 GPU 上的三个完整模型副本比较。
3. 使用 MiniCPM-V-2_6、FP16、TP=1，关闭动态角色切换与请求内编码并行；沿用固定 COCO 子集、预处理和提示词，目标输出 128 tokens。qjh003 测试每请求 1/4 张图、并发 1/4/8；qjh005 测试 1 图/并发 1、4 图/并发 8。每配置预热 20 请求，正式 100 请求，重复三次。
4. 记录吞吐、输出 tokens/s、TTFT、TPOT、端到端延迟 P50/P95、采样峰值显存、失败率和运行波动。交付启动及压测脚本、环境清单、必要补丁、逐请求数据、对照图和报告；保留 sapphire3 的失败诊断。

完成标准：通信数据一致、三阶段及并发正确性通过、公平基线与约定矩阵完成，结论有原始记录支撑；按用户提供的AGENTS.md完成G1–G5独立只读审查，优先Claude，Claude额度耗尽时由独立subagent接替，G5须为APPROVE或APPROVE_WITH_NITS。允许无加速或出现退化，不要求达到论文A100的加速倍数。

执行边界：仅使用确认空闲的 GPU，不中断他人任务；环境、模型、缓存和临时文件放专属数据盘目录；本轮不做跨机阶段拆分、通信层重写或全量消融。
