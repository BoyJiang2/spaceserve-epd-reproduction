# 最终文字补充

## 四个问题的回答

1. **能否运行、机制是否成立？** 两台H20在已披露的最小兼容补丁和cuBLAS覆盖下跑通EPD三阶段、原生传输及固定并发检查。SpaceServe在4090/L20跑通编码解耦和实际并发重叠；SM mask只在L20验证成功，公开fork不等于论文完整调度。
2. **收益与退化？** EPD的八个已测点吞吐均低于同三卡基线；TTFT P95在C1/C4变差、C8略好，E2E P95除qjh003的4图/C4外都变差。SpaceServe高负载吞吐收益伴随TTFT P95增加：4090的4图/C8为1250.2→2146.5ms，L20为1333.3→1977.8ms，启用mask为1696.7ms；这些高负载点的TPOT和E2E P95改善。
3. **限制来自哪里？** H20 cuBLAS兼容问题已解决，4090的SM mask不可用；H20通信数据正确但开销未定量归因，sapphire3损坏原因未做维护因果实验。没有正式请求失败，EPD物理显存采样峰值更高；单解码卡对三副本以及Ray/逐块提交可能影响结果，但尚未隔离调度因果。
4. **下一轮是否扩大？** 先围绕退化点做阶段GPU profiling和PD基线，再依据视觉负载、批量效率及通信开销决定扩大图片数量、分辨率或模型；当前不支持直接外推论文倍率。


4090均值高于基线的四点中，三个差值与重复标准差同量级；L20无mask低负载1.01×也在波动内。baseline-epd-l20仅作完整模型测量保留，不支撑对应诊断EPD性能结论。
